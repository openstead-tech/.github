# Openstead

### Deploy apps, APIs and databases without managing servers.

Openstead is a managed cloud platform for developers and small teams. Deploy applications from GitHub, connect managed PostgreSQL and MySQL databases, and manage domains, environment variables, logs and deployments in one place.
